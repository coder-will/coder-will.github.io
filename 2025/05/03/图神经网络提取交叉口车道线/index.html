图神经网络提取交叉口车道线

发表于2025-05-03|更新于2025-05-03
|浏览量:

  • 出发点

    高精度轨迹采样频率高，位置可靠，同时能够反映车辆在交叉口真实行进路线。因此本方法直接从交叉口轨迹中选取各车道代表性轨迹作为车道线。

    从而把交叉口车道线提取问题转化为：交叉口内部轨迹分类问题，轨迹将被分为两类：代表性/非代表性轨迹，最终直接将代表性轨迹作为车道线完成提取。

    具体是通过将交叉口内部轨迹转化为图结构，再通过图神经网络对图节点进行分类来实现轨迹分类。

  • workflow

    ①轨迹关系图构建：

    由于交叉口内部轨迹非常复杂，为了提取代表性轨迹，除了考虑轨迹自身特征外，还需要分析轨迹之间的关系。通过将每条轨迹作为一个节点，轨迹之间的关系作为边，从而为每个交叉口构建一个轨迹关系图。

    节点特征：轨迹自身特征，如：弯曲度、曲率、方向变化等；

    边特征：轨迹之间的距离特征，如：豪斯多夫距离，采样点距离等。

    注意一个交叉口内的每个轨迹之间都构建边，因此构建的图为全连接图

    ②模型：

    使用graph transformer network（torch_geometric.nn.conv.TransformerConv — pytorch_geometric documentation (pytorch-geometric.readthedocs.io)），以上述图为输入，经过一层GTN卷积层后，对输出节点嵌入使用sigmoid函数（二分类）输出节点为代表性轨迹概率，最终取输出概率大于70%的节点为代表性轨迹；

    ③loss以及数据集制作

    虽然任务是对轨迹进行分类，但传统的分类loss如交叉熵损失会存在如下问题：

    通常情况下，每条车道平均有超过10条轨迹经过。这些轨迹非常接近，并且具有相似的形状和方向特征。交叉熵损失独立考虑分类概率，忽略预测之间的关系，这不可避免地导致模型对单个车道预测多个代表性轨迹，导致冗余车道的提取。

    受到目标检测领域的DETR（End-to-End Object Detection with Transformers）启发，设计了基于集合的loss用于本任务。

    具体来说，该loss并不单独考虑每个节点分类概率，而是将一个交叉口预测结果作为一个预测集合，将真值路网结果作为真值集合，将二者进行二分匹配，根据匹配结果计算loss，从而整体分析每个交叉口提取结果。具体计算方式与DETR类似（https://blog.csdn.net/qq_54185421/article/details/125992305）

    数据集制作：对每个交叉口手工画出各车道线。后续训练时通过模型输出结果与真值车道线进行二分匹配计算loss。
